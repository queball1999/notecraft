# NoteCraft app icon

Original artwork by The NoteCraft Contributors, licensed MIT OR Apache-2.0 like the rest of the repo (row in ATTRIBUTION.md).

- `notecraft.svg` is the source: a full-bleed 512 px tile (corner radius 112) in the NoteCraft purple, with a ruled page and a handwritten ink stroke. It is not modeled on any vendor's logo.
- Everything else here is generated by `packaging/icons.sh` (needs `resvg`): `notecraft-1024.png`, `notecraft-macos-512.png`, the Linux `hicolor/` theme, `notecraft.ico` (Windows), and `notecraft.icns` (macOS, on Apple's 824/1024 icon grid).
- Edit the SVG, run `packaging/icons.sh`, and commit every output together.
